INDIVIDUAL SKILLS:

1️⃣  IMPORT CHECKER
   npm run check:imports
   ↳ Verifies ESM import/export wiring
   ✓ Finds missing/invalid imports
   ✓ Detects export mismatches
   ✓ Catches broken module wiring
   When: After adding new JS file

1️⃣.5  ESM COVERAGE CHECKER
   npm run check:esm-coverage
   ↳ Reports files not yet migrated to ESM
   ✓ Tracks migration progress
   ✓ Lists remaining non-ESM files
   ✓ Prevents hidden CommonJS drift
   When: During/after ESM migration work

2️⃣  SYNTAX VALIDATOR
   npm run check:syntax
   ↳ Catches syntax errors that kill entire files
   ✓ Duplicate const in same scope
   ✓ Unclosed brackets/parentheses
   ✓ Missing commas in objects
   When: Before tests or if "not a function" error

3️⃣  RLS POLICY CHECKER
   npm run check:rls
   ↳ Verifies Supabase RLS is enabled
   ✓ Lists tables being queried
   ✓ Provides RLS policy template
   ✓ Manual verification checklist
   When: After creating new Supabase table

4️⃣  SUBSCRIPTION CLEANUP AUDITOR
   npm run check:subscriptions
   ↳ Finds memory leaks in real-time subscriptions
   ✓ Detects unsubscribed channels
   ✓ Shows auto-cleanup features
   ✓ Prevents listener accumulation
   When: After adding real-time feature

5️⃣  MOBILE BREAKPOINT VERIFIER
   npm run check:mobile
   ↳ Scans CSS for responsive design
   ✓ Checks mobile-first layout
   ✓ Verifies @media queries
   ✓ Tests at 375px, 768px, 1920px
   When: After creating new CSS file

6️⃣  MODAL STATE AUDITOR
   npm run check:modals
   ↳ Audits modal data cleanup
   ✓ Finds showModal() without closeModal()
   ✓ Detects state pollution
   ✓ Verifies initialization checks
   When: After adding new modal

7️⃣  STATE VARIABLE TRACKER
   npm run check:state
   ↳ Tracks global state variables
   ✓ Lists variables from state.js
   ✓ Shows usage locations
   ✓ Flags undeclared globals
   When: Before creating new state variable

8️⃣  TEST COVERAGE REPORTER
   npm run check:coverage
   ↳ Runs Jest and shows coverage
   ✓ Identifies untested code
   ✓ Recommends test scenarios
   ✓ Shows coverage by file
   When: Before committing

COMMON BUG PATTERNS:

Bug: "function is not a function"
→ npm run check:syntax
→ npm run check:imports

Bug: Empty data from Supabase query
→ npm run check:rls

Bug: App slowing down / memory issues
→ npm run check:subscriptions

Bug: Mobile layout broken
→ npm run check:mobile

Bug: Modal shows old data
→ npm run check:modals

Bug: Unexpected state behavior
→ npm run check:state

   ↓
