# Parts Database

## What this page is for
Parts Database is the reusable reference list for part-level data.
It supports BOM setup and process/resource linkage.

## Data quality essentials
- Use consistent part numbering.
- Keep descriptions clear enough for fast selection.
- Apply classification fields consistently so filtering remains useful.
