# Operations Overview Tab

## What this tab is for
This is the first-stop health check for the whole operation.
Use it to decide where to investigate before diving into detailed tabs.

## How to use it day-to-day
1. Scan the headline indicators.
2. Check recent changes or alerts.
3. Jump directly to the source area that needs attention.

## When to trust this tab vs drill deeper
- Use Overview for prioritization.
- Use Flow, Risk, People, and Actions tabs for root-cause analysis.
