# Operations Actions Tab

## What this tab is for
Actions gives a cross-project execution view so overdue work does not get hidden inside individual portals.

## Practical use
1. Start with overdue actions.
2. Check whether each item has a clear owner and realistic due date.
3. Open source context where clarification is needed.
4. Confirm status updates are reflected back in source records.

## Why this tab is important
Risk decisions only matter if actions are completed.
This tab is where planning turns into delivery accountability.
