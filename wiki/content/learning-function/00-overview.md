# Learning Function

## What this lens is for
Use the Function lens when you want to understand what a tool is, why it exists, and how it connects to APQP outcomes.

This lens answers:
- What problem does this tool solve?
- What good output looks like?
- How it links to other quality and delivery functions?

## How to use this lens effectively
1. Start with the function overview page for your area.
2. Identify inputs, outputs, and owners for that function.
3. Confirm what "good quality output" means.
4. Only then move into process click-path execution.

## Function-first learning pattern
Use this simple pattern for any module:

| Step | Question to answer | Example output |
|---|---|---|
| Purpose | Why does this function exist? | "Capacity prevents overload and missed dates" |
| Inputs | What data must be correct first? | Team hours, production forecast |
| Outputs | What decision does this function support? | Rebalance monthly load |
| Dependencies | What connected modules influence it? | Production, Action Centre |

## Why this matters
Teams that skip function understanding often do the right clicks for the wrong reason.
Function-first learning improves data quality, decision quality, and handover quality.
