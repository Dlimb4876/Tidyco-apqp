# Operations Process Workflow

## Daily operational review flow
1. Start at [Operations Overview Tab](../operations/10-overview-tab.md).
2. Triage issues by severity and urgency.
3. Drill into the matching tab: Flow, Risk, People, Actions, or Forecast.
4. Route actions to owning teams and track follow-through.

## Weekly pattern
1. Compare trend direction, not just single-day values.
2. Confirm unresolved issues are linked to owned actions.
3. Escalate persistent red/amber conditions.

## Tab-by-tab workflow cue
| Tab | Primary question | Typical action |
|---|---|---|
| Overview | Are we on-track overall? | Raise priority exceptions |
| Flow | Where is throughput constrained? | Re-sequence work |
| Risk | What could break delivery? | Add mitigation actions |
| People | Do we have enough staffing? | Rebalance assignments |
| Actions | Are owners moving blockers? | Escalate stalled items |
| Forecast | What is likely next? | Pre-plan capacity and support |

## Common process failures
- Seeing issues but not creating owned actions
- Escalating symptoms without root cause context
- Reviewing only daily values without trend direction
