# Action Centre Process Workflow

## Primary workflow
1. Open [Action Centre Overview](../action-centre/00-overview.md).
2. Start with overdue items.
3. Confirm owner, due date, and next update.
4. Open source context for each blocked item.
5. Update status and close only with clear outcome.

## Daily ownership checks
- Every open action has one named owner
- Every open action has a next step and due date
- Blocked actions have dependency notes
- Closed actions include evidence or resolution context

## Weekly team review checks
1. Remove duplicates.
2. Reassign stale ownership.
3. Escalate aging overdue actions.
4. Confirm closure quality for sampled items.

## Common process failures
- "In Progress" items with no updates for long periods
- Closing actions without clear resolution evidence
- Keeping shared ownership without a lead owner
