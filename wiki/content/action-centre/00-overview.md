# Action Centre

## What this area is for
Action Centre is the shared execution queue across projects and modules.
It helps teams prioritize what needs action now, especially overdue and blocked items.

## Best way to use it
1. Start with overdue items.
2. Confirm each item has an owner and next step.
3. Use source links to update details in the originating record.
