How Capacity Is Calculated
Formula
Capacity = Staff x Working Days x 8 hours x Utilization Factor
Working Days
Working days include Monday to Friday and exclude UK bank holidays.
Baseline
The baseline is 40 hours per person per week (5 days x 8 hours), then adjusted by the utilization factor set in Capacity Settings.

ABC Inventory Classification
A
Class A — High Value / Critical
Typically top ~10–20% of parts by value or criticality. Tightly controlled, closely monitored stock levels. Usually the smallest number of unique parts.
B
Class B — Medium Value
Middle tier ~30% of parts. Moderate control. Reviewed periodically. Larger number of unique parts than A.
C
Class C — Low Value / Common
Typically ~50–70% of unique part types but only ~5–10% of total value. Fasteners, consumables, standard fixings. Often bulk-stocked. These are shared across projects and tracked in the C-Class Catalogue.
