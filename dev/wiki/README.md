# Wiki Authoring Guide

This wiki helps both new and existing Tidyco APQP users quickly understand the platform and its features.

## Writing style

Write every article in an encyclopedic, accessible tone.

- Encyclopedic: factual, structured, and neutral
- Accessible: plain language, clear headings, and minimal jargon
- User-focused: explain what something is, why it matters, and when to use it

## Feature documentation expectations

Each feature article should include a high-level overview that explains how to use the feature in everyday work.

Include:

- What the feature does
- Who should use it
- The normal workflow to use it
- Any important limits, permissions, or prerequisites

## Calculations and formulas

Where calculations are relevant, include a dedicated detailed section that explains:

- What is being calculated
- The formula or logic used
- Inputs required
- How to interpret the result

Keep calculation sections clear and step-by-step so users can follow and validate outcomes.
