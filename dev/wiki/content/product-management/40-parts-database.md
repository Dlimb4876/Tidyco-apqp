# Parts Database

## What this page is for
The Parts Database is the central reference library for all physical items consumed during manufacturing or overhaul.
It supports accurate Bill of Materials (BOM) construction across all NPI projects.

## Before you start
- Gather standard part numbers, descriptions, and categories from your ERP or procurement system.

## Key components
- **Item Number:** The unique identifying code (e.g., SKU or Part Number).
- **Description:** A clear, unambiguous name.
- **Category:** Classification (e.g., Part, Material, Consumable, Tool).

## The management process
1. **Standardize:** Enter items with consistent naming conventions.
2. **Categorize:** Assign the correct category so engineers can filter easily when building a BOM.
3. **Maintain:** Archive obsolete parts so they aren't accidentally selected for new projects.

## Common mistakes to avoid
- **Vague descriptions:** Naming an item "M8 Bolt" instead of "M8x20 Hex Head Bolt SS".
- **Category confusion:** Mixing up "Materials" (raw stock to be machined) with "Consumables" (shop supplies like grease).
- **Duplicate entries:** Creating multiple records for the exact same physical part due to slight naming variations.

## Quick example
| Category | Item Number | Description |
|---|---|---|
| Part | BRG-102 | Main Flange Bearing |
| Consumable | LOC-243 | Loctite Threadlocker Blue 5ml |
| Tool | FIX-99 | Bearing Alignment Fixture |
