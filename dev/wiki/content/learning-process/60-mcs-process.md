# MCS Process Workflow

## Primary workflow
1. Raise change in [MCS Overview](../mcs/00-overview.md).
2. Complete impact assessment details.
3. Complete Approval 1.
4. Execute implementation stage with evidence.
5. Complete final approval and close-out.

## Stage quality checks
| Stage | Minimum quality bar |
|---|---|
| Raise | Scope and reason are clear |
| Impact | Affected functions are explicitly listed |
| Approval 1 | Decision rationale is documented |
| Implement | Evidence shows what was changed |
| Final approval | Verification is complete and traceable |

## Common process failures
- Routing for approval before impact is complete
- Using vague implementation notes without evidence
- Closing requests before verification is captured
