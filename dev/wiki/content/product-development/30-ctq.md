# CTQ Matrix

## What this page is for
CTQ (Critical to Quality) defines the measurable requirements that must be met.
It is the reference point for what good looks like and how it will be verified.

## What to capture clearly
- The requirement statement
- Target and tolerance values
- How it will be tested or inspected
- Source reference (customer, drawing, spec, standard)
- Optional link to the process step in PFD

## Why this matters
If CTQ values are vague, downstream PFMEA and Control Plan entries become inconsistent.
Clear CTQs improve traceability from requirement to control.
