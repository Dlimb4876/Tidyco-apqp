# Control Plan

## What this page is for
Control Plan defines how each key process step will be controlled in day-to-day execution.
It translates risk analysis into practical prevention and detection checks.

## What to define clearly
- Control method
- Control frequency
- Responsibility
- Reaction plan when results are out of control
- Link to CTQ and process step where possible

## Recommended flow
1. Build or sync baseline controls from PFMEA.
2. Validate each control against CTQ requirements.
3. Confirm reaction plans are specific and actionable.
