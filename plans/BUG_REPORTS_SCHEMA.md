# Bug Reports Schema — Fully Relational

## Table: `bug_reports`

All bug report data is stored in individual relational columns (no JSON blobs).

### Column Definitions

| Column | Type | Nullable | Purpose |
|---|---|---|---|
| `id` | UUID | No | Primary key (auto-generated by Supabase) |
| `user_id` | UUID | No | Supabase auth user ID (who created the report) |
| `raised_by` | text | No | Email of the user who raised the bug |
| `date_raised` | timestamp with tz | No | ISO 8601 timestamp when bug was reported |
| `page` | text | Yes | Which page/area the bug was found (e.g., "PFMEA", "Production Scheduling") |
| `description` | text | No | Full bug report description (required field) |
| `status` | text | No | One of: `'open'` or `'closed'` (default: `'open'`) |
| `response` | text | Yes | Response/fix description (only set when status = 'closed') |
| `responded_by` | text | Yes | Email of responder (only set when responded) |
| `responded_at` | timestamp with tz | Yes | When the response was submitted |
| `created_at` | timestamp with tz | No | Supabase system column (auto-set) |
| `updated_at` | timestamp with tz | No | Supabase system column (auto-updated) |

## RLS Policy

The table requires an RLS policy to enforce authentication:

```sql
-- Enable RLS
ALTER TABLE bug_reports ENABLE ROW LEVEL SECURITY;

-- Allow all authenticated users to read all bug reports
CREATE POLICY "Allow authenticated users to read bug reports"
ON bug_reports
FOR SELECT
USING (auth.role() = 'authenticated');

-- Allow authenticated users to insert their own bug reports
CREATE POLICY "Allow authenticated users to insert bug reports"
ON bug_reports
FOR INSERT
WITH CHECK (auth.role() = 'authenticated' AND user_id = auth.uid());

-- Allow all authenticated users to update any bug report (for responses)
CREATE POLICY "Allow authenticated users to update bug reports"
ON bug_reports
FOR UPDATE
USING (auth.role() = 'authenticated');
```

## Code Implementation

### Loading (in `portals/bugs/js/bugs-data.js`)

```javascript
async function bugDataInit() {
  if (!currentUser) return;
  const { data, error } = await supa
    .from('bug_reports')
    .select('*')
    .order('date_raised', { ascending: false });
  bugState.reports = data || [];
}
```

### Creating a New Report

```javascript
const report = {
  user_id: currentUser.id,
  raised_by: currentUser.email,
  date_raised: new Date().toISOString(),
  page: 'PFMEA',
  description: 'Bug description',
  status: 'open'
};
await supa.from('bug_reports').insert([report]).select();
```

### Updating Status / Adding Response

```javascript
const updates = {
  response: 'Fix applied',
  responded_by: currentUser.email,
  responded_at: new Date().toISOString(),
  status: 'closed'
};
await supa.from('bug_reports').update(updates).eq('id', reportId);
```

### Real-Time Sync

The UI subscribes to live updates:

```javascript
createRealtimeSubscription('bug_reports', 'bug_reports_channel', {
  onInsert: (newReport) => {
    bugState.reports.unshift(newReport);
    render();
  },
  onUpdate: (updated) => {
    const idx = bugState.reports.findIndex(r => r.id === updated.id);
    if (idx >= 0) bugState.reports[idx] = updated;
    render();
  },
  onDelete: (deleted) => {
    bugState.reports = bugState.reports.filter(r => r.id !== deleted.id);
    render();
  }
});
```
